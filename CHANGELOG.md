# Changelog

All notable changes to this skill are listed here, newest first.

## 1.0.0 - 2026-11-06

First version.

- Skill `gemini-image-gen`: generates images by driving gemini.google.com in Chrome with the user's own Gemini account.
- Batches several images into one Gemini chat to keep Claude usage down.
- Brings files into Claude by Downloads folder access, or by drag and drop.
- Documentation added: setup, usage, how it works, troubleshooting, alternatives.

Tested once: one image, about 40 seconds, about 15 browser steps, downloaded at full size (about 2 MB) and used as the hero picture of a landing page.
